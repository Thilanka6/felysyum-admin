# Admin Panel - Next.js Version

This is the Next.js port of the PHP Admin Panel.

## Setup

The project requires Node.js dependencies to be installed.

1. Open your terminal.
2. Navigate to this directory:
   ```bash
   cd admin-nextjs
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
   *This will fix the "Cannot find module" errors in your IDE.*

## Development

To start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Structure

- `src/app`: App Router pages and layouts.
- `src/components`: Reusable UI components (Sidebar, Header, etc).
- `public`: Static assets (images).
